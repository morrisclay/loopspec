# LoopSpec documentation website

The Astro Starlight site for the LoopSpec v1.1 language and canonical IR v2.1.

## Work locally

```bash
npm install
npm run dev
```

The site runs at `http://localhost:4321` by default.

## Validate the site

```bash
npm run check
```

This synchronizes canonical repository documents, builds all routes and search indexes, prepares
the static worker, and verifies every internal route, anchor, required asset, and starter cleanup.

## Content ownership

Task-oriented pages live directly under `src/content/docs/`. Ten long-form reference pages are
generated by `scripts/sync-content.mjs` from the repository's existing canonical Markdown:

- `REFERENCE.md` and `docs/CHECKS.md`;
- `CYBERNETICS.md`, `ATTENTION.md`, and `CALIBRATION.md`;
- `RULESET.md`, `NOTATION.md`, and `COMPATIBILITY.md`;
- `docs/LINTING-EXISTING.md` and `docs/COOKBOOK.md`.

Edit those source files rather than their generated website copies. Every build refreshes them.
