# Historical archive

This directory contains superseded project premises, old scorecards, rejected theses, and early
field instruments. It exists so the research trajectory remains auditable without making new
LoopSpec users navigate obsolete framing.

Nothing here defines the current language or its supported claims.

- [`uras/`](uras/) contains the original universal-representation programme, its status record,
  benchmark corpus, adjudication, score machinery, pivot briefing, and handoff material.
- [`THESIS.md`](THESIS.md) preserves the early agent-loop product thesis and later corrections.
- [`field-tests/`](field-tests/) contains early practitioner instruments that do not count as
  completed external validation.
- [`autoresearch/`](autoresearch/) contains completed autonomous development ledgers, including
  rejected cycles and ceiling handoffs.

For current material, return to the [`research index`](../README.md), the active
[`convergence record`](../CONVERGENCE.md), or the product [`README`](../../README.md).
